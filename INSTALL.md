# Installation Guide - Claude AI (Free)

Welcome to **Claude AI** - a 100% free, no backend, no server costs solution!

## Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- An internet connection
- A free Anthropic API key (optional, for enhanced features)

## Installation Methods

### Method 1: Direct Browser Access (Simplest)

1. **Clone or download this repository**
   ```bash
   git clone https://github.com/Dolfi24/unlimited-claude-AI.git
   cd unlimited-claude-AI
   ```

2. **Open `index.html` directly in your browser**
   - Double-click `index.html` file, or
   - Right-click `index.html` → "Open with" → Select your browser

3. **Start using Claude AI immediately** - No installation needed!

### Method 2: Using a Local Server (Recommended)

For better security and reliability, run a local server:

#### Using Python 3
```bash
# Navigate to the project directory
cd unlimited-claude-AI

# Python 3.x
python -m http.server 8000

# Then open: http://localhost:8000
```

#### Using Node.js
```bash
# Install http-server globally (one-time)
npm install -g http-server

# Run in project directory
http-server

# Then open the provided local URL (typically http://localhost:8080)
```

#### Using PHP
```bash
# Navigate to project directory
php -S localhost:8000

# Then open: http://localhost:8000
```

## Getting Started

### Free API Setup

#### Option A: Use Built-in Free API (No Setup Required)
The app works out-of-the-box with pre-configured free API endpoints.

#### Option B: Add Your Own Free API Key

**Get a free Anthropic API key:**
1. Visit [console.anthropic.com](https://console.anthropic.com)
2. Create a free account
3. Generate an API key from the dashboard
4. Copy your API key

**Add the API key to the app:**
1. Open the application in your browser
2. Locate the Settings/Configuration section
3. Paste your API key
4. Your key is stored locally (never sent to our servers)

## Troubleshooting

### "File not found" or blank page
- Make sure you're opening the correct `index.html` file
- Try running a local server (see Method 2 above)
- Check browser console for errors (F12 → Console tab)

### API errors
- Verify your internet connection
- Check that your API key is valid (if using custom key)
- Try refreshing the page
- Clear browser cache and cookies

### App not responding
- Clear browser cache
- Disable browser extensions
- Try a different browser
- Check browser console for errors
